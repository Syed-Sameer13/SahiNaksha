# SIH Demo Script

## Scenario
Use a small urban survey area. Clearly state whether parcel data is synthetic, reference-only or authoritative.

## Demo
1. Login as Surveyor.
2. Create urban survey project.
3. Upload orthomosaic.
4. Start AI analysis.
5. Show processing stages.
6. Display orthomosaic, parcels, buildings, roads and issues.
7. Select a parcel.
8. Show ID, estimated area, confidence/review score, issues and reference comparison.
9. Edit an uncertain boundary.
10. Save the surveyor decision.
11. Open topology dashboard and show an example issue.
12. Export GeoJSON and report.

## Key explanation
“SahiNaksha does not declare legal ownership from imagery. It generates preliminary GIS-ready features, highlights uncertainty and geometry conflicts, and provides a surveyor verification layer.”

## Avoid
- claiming synthetic data is official
- claiming legal certification
- inventing accuracy percentages
- claiming live CORS integration when it is not actually connected
