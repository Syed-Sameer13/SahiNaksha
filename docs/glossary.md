# SahiNaksha Glossary

**Cadastral map** — A map representing land parcels and related survey information.

**Parcel** — A defined land unit used in a cadastral system.

**Building footprint** — The mapped footprint of a building.

**Orthomosaic** — A georeferenced, distortion-corrected mosaic created from aerial images.

**DSM** — Digital Surface Model; includes surfaces such as buildings and trees.

**DTM** — Digital Terrain Model; represents terrain/bare earth.

**CRS** — Coordinate Reference System.

**EPSG** — Standard identifier for coordinate reference systems.

**Raster** — Pixel/grid-based spatial data.

**Vector** — Point, line and polygon spatial data.

**GeoJSON** — JSON format for geographic vector data.

**Topology** — Spatial relationships and geometry rules.

**Segmentation** — Assigning pixels to meaningful regions/objects.

**Polygonization** — Converting masks/raster regions into vector polygons.

**GeoPandas** — Python library for geospatial vector data.

**Shapely** — Python library for geometric operations.

**PostGIS** — Spatial extension for PostgreSQL.

**GNSS** — Global Navigation Satellite System.

**CORS** — Continuously Operating Reference Station network used to improve positioning.

**Ground truth** — Field-verified reference information used to assess mapping.

**WebGIS** — GIS functionality delivered through a web application.

**Preliminary cadastral feature** — An AI/imagery-derived candidate feature requiring authorized verification.
